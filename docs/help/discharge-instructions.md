# Prepare discharge instructions

Use **New → Discharge instructions** in your signed-in practice to write a
take-home handout. You can start with a patient name and your own instructions,
even when the patient's record is in another PIMS.

Veterinarians, technicians, and practice administrators can use the tool. On
OpenVPM Cloud, the practice needs an active trial or subscription. Self-hosted
practices can use it with no hosting subscription. A practice under a recovery
hold returns to the imported-history workspace.

1. Enter the **Patient name** and check the **Clinic contact**. The handout
   starts with the phone number on file for your practice.
2. Write the **Home care** instructions. Add **When to call the clinic** and
   **Follow-up** if you want those sections on the handout.
3. Select **Review handout**. Check the patient name, practice, contact, and
   every instruction. Use **Edit instructions** to make a correction.
4. Select **Print handout** to open your browser's print dialog. Choose the
   intended printer or save a PDF. To file it in a PIMS, choose
   **Copy instructions**, open the correct patient and visit, paste the text,
   check it, and save the record yourself. If clipboard access is unavailable,
   copy the selected text shown on screen.

The draft stays in the tab. OpenVPM does not send it to the owner or save it
to a chart. Your system clipboard, printer, and any PDF you save handle the
copies you create. After saving or sharing the handout, select **Start another
handout** and confirm to clear the previous patient's details.
