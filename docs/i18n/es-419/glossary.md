# Spanish (Latin America) glossary

This path is a proposal for terminology notes. Confirm it with a maintainer
before treating it as the canonical glossary.

The strings in `apps/web/messages/es-419.json` are a machine draft for native
review on [#346](https://github.com/evangauer/openvpm/issues/346). They are not
a regulatory, tax, or prescribing glossary.
