# Italian glossary

This path is a proposal for terminology notes. Confirm it with a maintainer
before treating it as the canonical glossary.

The strings in `apps/web/messages/it.json` are a machine draft for native
review. They are not a regulatory, tax, or prescribing glossary. Italian
fiscal, invoicing, and prescription workflows stay out of translation files.
See [docs/I18N.md](../../I18N.md).
